# SIH Screening Readiness Checklist

## Submission identity

- [ ] Team name exactly matches SIH portal
- [ ] Problem statement ID exactly matches SIH portal
- [ ] Problem statement title exactly matches SIH portal
- [ ] Category is Software
- [ ] Theme matches portal entry
- [ ] Six members and mentor details match institute/portal records

## PPT / PDF

- [ ] Official template only
- [ ] No changed headers, margins or structure
- [ ] Within official slide limit
- [ ] Architecture/data-flow diagram included
- [ ] USP/novelty stated explicitly
- [ ] Feasibility, security and scalability included
- [ ] Working prototype screenshots included
- [ ] Exported filename follows `<TeamName>_<ProblemStatementID>.pdf`

## Working software proof

- [x] Deployed interactive frontend
- [x] Driver map/geolocation prototype
- [x] Booking / QR / cancellation prototype
- [x] Owner operations prototype
- [ ] Real API connected
- [ ] Persistent database pipeline connected
- [ ] YOLO inference script/module runs on sample video or camera input
- [ ] Detection event updates API/database
- [ ] Frontend reflects a real backend event

## GitHub

- [ ] Repository created
- [ ] Team members added as collaborators
- [ ] README complete
- [ ] Live demo URL added
- [ ] Architecture/security docs added
- [ ] Issues created for remaining technical milestones
- [ ] Meaningful commit history maintained from now onward
- [ ] Build CI passes
- [ ] Release/tag created for screening submission

## Demo video

- [ ] 1–3 minutes
- [ ] Working product visible in first 45 seconds
- [ ] Real GPS/map shown
- [ ] Booking shown
- [ ] Owner entry/exit shown
- [ ] Real API/YOLO proof shown if completed
- [ ] Unlisted YouTube or accessible Drive link tested in incognito
