# 2-Minute Screening Demo Script

## 0:00–0:15 — Problem to product
Open SPF directly on **Explore Indore**. Allow browser location and show nearby facilities with live-style availability.

## 0:15–0:35 — Driver flow
Open a facility, show EV/PWD resources, reserve a space and display the QR confirmation.

## 0:35–0:55 — Owner flow
Open the Owner Dashboard, select the same facility and show ENTRY/EXIT movement, occupied/available state and resource utilisation.

## 0:55–1:25 — Technical proof
Show the current/next screening vertical slice: sample video or camera -> YOLO detection -> generated vehicle event -> API/database -> updated SPF availability.

## 1:25–1:45 — USP
Explain the low-cost retrofit approach and reservation-aware occupancy reconciliation.

## 1:45–2:00 — Scale
Show facility-by-facility data model, security/privacy direction and city-scale rollout path.

Keep introductions short. Put working proof on screen within the first 45 seconds.
